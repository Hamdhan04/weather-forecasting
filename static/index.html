Recurrent Mathematical Formulations

Forget Gate Equation
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)

Eliminates obsolete meteorological diurnal memory from prior cycles.

Candidate & Cell Update
C_t = f_t ⊙ C_{t-1} + i_t ⊙ tanh(W_c · [h_{t-1}, x_t] + b_c)

Accumulates synoptic pressure front gradients into persistent cell memory.

Output State Vector
h_t = σ(W_o · [h_{t-1}, x_t] + b_o) ⊙ tanh(C_t)

Generates the recurrent activation passed forward in time.

Loss: MSE Optimizer: Adam (1e-3) Scheduler: Plateau Decay Device: PyTorch CPU
